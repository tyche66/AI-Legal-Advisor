# 税务法核心框架参考（中国）— 供老板/创业者合规经营使用

**编制：2026-08-18，AI 审查草稿。定位：框架与红线速查，非税务意见。所有税率、起征点、优惠额度均须运行时检索官方公告后引用。**

> **⚠️ 使用前必读。**
> - 本文件**不硬编码具体税率、起征点、优惠比例**——这些由财政部/国家税务总局公告频繁调整，必须检索最新官方来源（税务总局、财政部）后引用，标注 `[已验证 — YYYY-MM-DD]`。见 `references/currency-watch-2026.md` 税务段。
> - 税务问题的最终判断应由**执业律师或注册税务师**做出；本 Agent 只做合规框架梳理、红线提示与问题清单。
> - 一切税务筹划以**业务真实、票流/资金流/货物（服务）流三流一致**为前提。脱离真实交易的"筹划"就是逃税/虚开。

## 一、主体选择与税负（创业者最先要想清楚的事）

不同经营主体的税负结构差异巨大，是合法降低整体税负的第一杠杆 `[模型知识 — 需验证]`：

| 主体类型 | 所得税层面 | 责任层面 | 适用场景（提示，非定论） |
|---|---|---|---|
| 有限责任公司 | 企业所得税 + 股东分红个税（存在"双重征税"） | 有限责任 | 需要融资、多股东、隔离风险 |
| 一人有限责任公司（OPC） | 同上；且财产混同举证倒置风险高 | 有限责任（易被击穿） | 独资但要责任隔离 |
| 个人独资企业 | 仅经营所得个税，无企业所得税 | 无限责任 | 轻资产、低风险、个人服务 |
| 合伙企业 | "先分后税"，合伙人各自纳税 | 普通合伙无限连带 | 多人合作、基金 |
| 个体工商户 | 经营所得个税（核定或查账） | 无限责任 | 小微、门店 |

**提示要点：** 责任隔离与税负轻是一对权衡（有限责任通常伴随双重征税；无限责任主体税负轻但风险大）。须结合业务风险、融资需求、退出安排综合建议，并提示"核定征收政策收紧"的趋势 `[模型知识 — 需验证]`。

## 二、增值税（《增值税法》2026-01-01 施行）

须检索核实后引用 `[联网检索 — 需复核]`：
- 纳税人区分（一般纳税人 / 小规模纳税人）与登记标准；
- 税率结构与征收率；
- 进项抵扣规则（合法取得专用发票、不得抵扣情形）——**进项管理直接决定税负**；
- 留抵退税、即征即退等优惠；
- 小规模纳税人起征点 / 免税月销售额（**以最新公告为准，必须检索**）。

## 三、企业所得税 / 个人所得税

`[模型知识 — 需验证]`，须检索最新政策：
- **企业所得税：** 基本税率、小型微利企业优惠、研发费用加计扣除、高新技术企业优惠——优惠条件与比例须核实。
- **个人所得税：** 综合所得、经营所得（个体户/个独/合伙）、股权转让所得、分红所得；专项附加扣除。
- **社保入税：** 社保由税务征收后的合规压力，与用工成本方案联动（见劳动用工与 SPC 劳动争议司法解释(二)）。

## 四、发票与金税四期（红线区）

金税四期"以数治税"下，多部门数据比对增强，票流/资金流/货物流不一致极易预警 `[模型知识 — 需验证]`：
- **虚开增值税专用发票罪**（刑法第 205 条）：无真实交易开票、代开、"买票抵扣"均属之，刑事风险极高。
- **逃税罪**（刑法第 201 条）：注意行政处罚前置——经税务机关依法下达追缴通知后补缴税款、滞纳金并接受行政处罚的，一般不予追究刑事责任（有例外与次数限制，须核实）`[模型知识 — 需验证]`。
- 常见风险动作提示（须避免或标注刑事敞口）：无票支出找票冲抵、私户收款隐匿收入、阴阳合同、关联交易转移利润无合理商业目的、滥用税收洼地/核定征收。

## 五、合法节税 vs 逃税：红线区分

| 合法（可建议，须真实业务支撑） | 违法（不碰、不教、不美化） |
|---|---|
| 主体与交易结构的合理选择 | 无真实交易的虚开、代开发票 |
| 依法享受小微、研发加计、区域性合规优惠 | 隐匿收入、私户收款不入账 |
| 合规的进项管理与成本费用列支 | 虚列成本、买票抵扣 |
| 合同税负条款的合理约定（价税分离、开票义务） | 阴阳合同、体外循环 |

**判断标准：** ①业务是否真实；②是否有合理商业目的（非以避税为唯一目的）；③三流是否一致；④是否符合税法明文规定的优惠条件。任一存疑即标 `[需审查]` 并升级税务师/律师。

## 六、合同中的税务条款（合同审查联动）

审合同时须提示的涉税点 `[模型知识 — 需验证]`：
- 价款是否**含税/不含税**、税率变动风险由谁承担；
- **开票义务、发票类型（专票/普票）、开票时间与付款的先后**；
- 未开票或开错票的违约责任；
- 跨境交易的代扣代缴义务（预提所得税、增值税）。

## 七、人工升级硬条件

以下必须明确提示"需注册税务师/税务律师复核，不可仅据此行动"：
- 涉嫌虚开、逃税、骗取出口退税等刑事风险；
- 重大重组、股权转让、跨境交易的税务安排；
- 依赖税收洼地/财政返还/核定征收的方案；
- 任何具体税率、优惠额度、申报口径的最终确认。

本文件是框架与红线速查。凡涉及具体数字（税率、起征点、优惠比例、金额门槛），一律先检索国家税务总局/财政部最新公告，再以 `[已验证 — YYYY-MM-DD]` 引用；未检索的表述保持 `[模型知识 — 需验证]` 并提示核实。最新立法动态见 `references/currency-watch-2026.md`。
