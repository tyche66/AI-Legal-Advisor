# /tax-legal:entity-tax-triage

1. 加载 `~/.claude/plugins/config/claude-for-legal-zh/tax-legal/CLAUDE.md` → 主体与税负画像、风险偏好。
2. 采集事实（缺失先问，不凭空建议）：业务模式、预计营收规模、股东人数、是否要融资/退出、风险高低、现有主体。
3. 参照 `../../references/tax-core-rules.md`（主体选择表）与 `../../references/entity-choice-opc-playbook.md`。
4. 对每个候选主体做**双轴 + 六维度**评价，产出方案对比与推荐。

## 目的

创业第一个决策就是"用什么主体经营"，它一次性决定税负结构、责任隔离和融资能力。本技能不替老板拍板，而是把 2–3 个候选主体的税负、责任、融资、合规成本摆清楚，给出推荐与理由，并标出必须由税务师/律师确认的点。

## 分流工作流

### 第一步：候选主体
根据事实列出可行主体（有限公司 / 一人有限公司(OPC) / 个人独资 / 合伙 / 个体工商户）。排除明显不适用的并说明原因。

### 第二步：逐主体评价
对每个候选，填写：

| 维度 | 内容 |
|---|---|
| 所得税结构 | 企业所得税+分红个税 / 仅经营所得个税 / 先分后税 `[模型知识 — 需验证]` |
| 责任隔离 | 有限（可能被人格否认）/ 无限 |
| 融资与退出 | 能否股权融资、股权转让便利度 |
| 税负测算 | ⚪ 具体税率/优惠**必须检索**核实，未核实标 `[模型知识 — 需验证]` |
| 法律风险 | 🔴/🟠/🟡（如 OPC 财产混同举证倒置、无限责任） |
| 商业摩擦 | 🔴/🟠/🟡（设立成本、合规负担） |

### 第三步：红线提示
- OPC：`[需审查]` 公私分账、年度审计、避免财产混同（公司法第23条第3款举证倒置）。
- 个独/个体户：无限责任提示；核定征收政策收紧须核实。
- "多开公司隔离风险"：警示横向人格否认与关联交易无商业目的的稽查风险。
- 依赖税收洼地/财政返还/核定征收：`[需审查]`，标注政策稳定性风险，升级税务师。

## 输出格式

冠工作成果页眉（按角色）。结构：
```
【结论】一句话推荐 + 核心权衡
【候选主体对比表】(含双轴评级；税率/优惠标 [需核实])
【推荐方案 + 理由】(合法性 / 税负 / 责任 / 融资 / 成本)
【红线与 [需审查] 事项】
【下一步】(检索核实哪些数字 / 需税务师确认什么)
```
数据量大时提供仪表板选项。

## 何时不使用
- 已定主体、只问某个具体税率 → 直接检索官方公告回答。
- 涉及重大重组/跨境架构 → 完整分析后硬性升级税务师+律师。

## 收尾
以 CLAUDE.md `## 输出规范` 的下一步决策树收尾，选项定制为本次产出（起草主体方案备忘录 / 升级税务师 / 补充营收与融资事实 / 监控政策 / 其他）。结尾固定"待专业人士复核事项"。
