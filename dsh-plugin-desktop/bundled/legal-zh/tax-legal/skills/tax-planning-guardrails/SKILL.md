# /tax-legal:tax-planning-guardrails

1. 加载 `~/.claude/plugins/config/claude-for-legal-zh/tax-legal/CLAUDE.md` → 风险偏好、红线校准。
2. 复述并拆解用户的方案（做什么、通过什么主体/交易、省什么税）。
3. 对照四项合法性标准逐一判断。
4. 判定：✅ 合法可用 / ⚠️ 有条件可用（需补真实业务/凭证）/ 🛑 违法（逃税或虚开）。

## 目的

老板要的是"合法地少交税"。本技能不劝退所有筹划，而是把方案按红线过一遍：真实业务支撑的合法优化留下并完善，脱离真实交易的"避税"坚决标红，并解释刑事/行政敞口，给出合法替代路径。守住"合法节税 ≠ 逃税"的边界。

## 四项合法性标准（逐一判断）

| 标准 | 判断 | 不通过的后果 |
|---|---|---|
| ① 业务真实 | 交易/用工/费用是否真实发生 | 不真实 → 虚开/逃税 🛑 |
| ② 合理商业目的 | 是否有避税之外的商业理由（非"唯一目的避税"） | 无 → 一般反避税调整风险 `[需审查]` |
| ③ 三流一致 | 票流/资金流/货物或服务流是否吻合 | 断裂 → 虚开风险 🛑 |
| ④ 符合优惠法定条件 | 是否真正满足优惠/征收方式的适用条件 | 不符 → 追缴+滞纳金+罚款 🟠 |

四项全过 → 合法优化，帮其完善留痕。任一不过 → 定性并给替代。

## 常见方案红线提示 `[模型知识 — 需验证]`
- **税收洼地 + 核定征收**：政策收紧、稳定性存疑，且须有真实业务落地；空壳"开票公司"= 虚开。`[需审查]`
- **工资拆成劳务/发票报销**：无真实交易的"发票冲工资"= 逃税/虚开。
- **关联交易转移利润**：缺合理商业目的、不符独立交易原则 → 特别纳税调整。
- **私户收款、阴阳合同、体外循环**：🛑 逃税。

## 输出格式

冠工作成果页眉。结构：
```
【方案复述】
【四标准逐项判断表】
【定性】✅ / ⚠️ / 🛑 + 法律/刑事 × 商业 双轴
【如不可行：合法替代路径】
【[需审查] 与升级】(涉刑或依赖洼地/核定 → 升级税务师+律师)
【须检索核实的数字/政策】
```

## 何时不使用
- 已确定合法、只问操作细节 → 直接答 + 提示留痕。
- 涉及跨境/重大重组 → 完整分析后硬性升级。

## 收尾
以下一步决策树收尾（起草合规方案备忘录 / 升级税务师 / 补充业务真实性证据 / 监控政策稳定性 / 其他）。结尾固定"待专业人士复核事项"与"不可直接据此行动的事项"。**绝不承诺"一定不会被查"或"绝对安全"。**
