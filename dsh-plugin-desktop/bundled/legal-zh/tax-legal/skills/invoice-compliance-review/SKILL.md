# /tax-legal:invoice-compliance-review

1. 加载 `~/.claude/plugins/config/claude-for-legal-zh/tax-legal/CLAUDE.md` → 发票与开票画像、红线校准。
2. 采集事实：交易是否真实、票流/资金流/货物或服务流是否一致、开票方与受票方关系、金额与税率。
3. 参照 `../../references/tax-core-rules.md`（发票与金税四期红线段）与 `references/currency-watch.md`。
4. 判定：✅ 合规 / ⚠️ 需规范 / 🛑 涉嫌违法（红线）。

## 目的

金税四期"以数治税"下，三流不一致极易预警。老板的高频问题——"没进项票怎么办""能不能找票抵扣""私户收款"——很多游走在虚开/逃税红线。本技能快速定性并把刑事敞口讲清楚，红线动作坚决拦下并给合法替代。

## 审查工作流

### 三流一致性检查（核心）
| 检查 | 问题 |
|---|---|
| 票流 | 开票方=真实供货/服务方？品名数量金额与实际一致？ |
| 资金流 | 付款方=受票方？收款方=开票方？是否走私户/第三方？ |
| 货物/服务流 | 交易是否真实发生？有无合同、物流、验收佐证？ |

三流一致 → 通常合规。任一断裂 → `[需审查]`，判断是否构成虚开。

### 红线识别（🛑 坚决拦下）
- **无真实交易开票/受票、代开、买票抵扣** → 涉嫌**虚开增值税专用发票罪**（刑法第205条）`[模型知识 — 需验证]`，刑事敞口极高。
- **隐匿收入、私户收款不入账、虚列成本** → 涉嫌**逃税罪**（刑法第201条）。提示逃税罪的行政处罚前置：经追缴通知补缴税款、滞纳金并受行政处罚的一般不追刑责，但有例外与次数限制 `[需审查]`。

### 合法替代（针对"没进项票"这类真实痛点）
- 向能开票的合规供应商采购；小规模供应商可代开。
- 选择适配的纳税人身份 / 简易计税（须核实适用条件）。
- 规范用工与费用报销取得合法凭证。
以上均须真实业务支撑，不得为凑票而虚构交易。

## 输出格式

冠工作成果页眉。结构：
```
【定性】✅ 合规 / ⚠️ 需规范 / 🛑 涉嫌违法 + 一句话理由
【三流一致性分析】
【风险】法律/刑事 × 商业摩擦 双轴；涉及罪名与敞口
【合法替代方案】(若原方案不可行)
【[需审查] 与升级】(涉刑一律升级税务师+税务律师)
```

## 何时不使用
- 纯会计科目/入账口径问题 → 属财务处理，提示咨询会计。
- 已进入稽查/约谈 → 立即升级税务律师，本技能仅做材料梳理。

## 收尾
以下一步决策树收尾（起草合规说明 / 升级税务律师 / 补充交易凭证事实 / 其他）。涉嫌虚开或逃税的，明确写"不可仅据此行动，必须咨询税务律师"。结尾固定"待专业人士复核事项"。
