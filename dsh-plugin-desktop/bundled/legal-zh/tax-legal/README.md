# 税务合规律师插件

面向各行各业老板、独立创业者、一人公司（OPC）与个体工商户的税务合规工作流：主体税负分流、发票与金税四期合规审查、合法节税与逃税红线审查、税收优惠与政策红利梳理。围绕"合法经营、平衡盈利"构建——既守住刑事与行政红线，也帮老板在合法范围内优化税负、用足政策。

**每项输出均为供律师/注册税务师复核的草稿——附引用、已标记——而非税务意见。** 一切筹划以业务真实、票流/资金流/货物（服务）流三流一致为前提。**本插件绝不硬编码税率、起征点、优惠额度**：这些由财政部/国家税务总局公告频繁调整，必须运行时检索官方来源后引用，并标注 `[已验证 — YYYY-MM-DD]`。

## 适用对象

| 角色 | 主要工作流 |
|---|---|
| **老板 / 创业者 / 个体户业主** | 主体税负分流、税收优惠梳理、发票合规自查 |
| **财务 / 会计** | 发票与金税四期合规审查、成本费用扣除 |
| **法务 / 外部律师** | 税务红线审查、涉税刑事风险识别、律师交接 |

## 首次运行：冷启动访谈

采集你的经营主体、行业、纳税人身份、开票模式、既有税务顾问与风险偏好，构建每项技能都会读取的实务画像。

配置存储于 `~/.claude/plugins/config/claude-for-legal-zh/tax-legal/CLAUDE.md`，插件更新后继续生效。

```
/tax-legal:cold-start-interview
```

## 指令

| 指令 | 功能 |
|---|---|
| `/tax-legal:cold-start-interview` | 冷启动访谈，建立税务实务画像 |
| `/tax-legal:entity-tax-triage` | 主体税负分流：选/改经营主体，权衡责任隔离与税负 |
| `/tax-legal:invoice-compliance-review` | 发票与金税四期合规审查，识别虚开/逃税风险 |
| `/tax-legal:tax-planning-guardrails` | 对拟采取的节税方案做合法节税 vs 逃税红线审查 |
| `/tax-legal:incentive-finder` | 梳理可合法适用的税收优惠与政策红利（小微、研发、民营经济促进法等） |
| `/tax-legal:matter-workspace` | 多客户/多主体事项工作区管理 |
| `/tax-legal:customize` | 定制实务画像 |

## 边界

本插件做税务合规框架梳理、红线提示与问题清单，**不替代注册税务师/税务律师的专业意见，不做具体税额测算的最终确认，不承诺税务处理结果**。涉嫌虚开、逃税、骗取退税等刑事风险，或重大重组/跨境/税收洼地安排，硬性升级专业人士。
